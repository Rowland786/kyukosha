01
两样东西

ID 去哪找，视频怎么录

1.Roblox ID

头顶那行字是游戏里的角色名，可以随时改，不能当 ID。在游戏里按 MENU 打开 PLAYERLIST，能看到每个角色对应的 Roblox 用户名。也可以打开对方的 Roblox 主页：@ 后面是用户名，网址里那串数字是 ID。

用户名和数字 ID 填一个就行。提交时网站会去 Roblox 查，查不到会提示你。

2.视频

从违规开始录到结束，中间不剪、不加速。画面里要能认出是谁，录的时候打开一次 PLAYERLIST。压制、扛着人不放这类持续的行为，要录够两分钟。

不收 OBS 录屏 可以用手机自带录屏、Windows 的 Xbox Game Bar（Win + G）或 Medal。视频可以直接上传，也可以贴 B 站、网盘等不用登录就能打开的链接。

02
处理流程

交上来以后

  1. 01

    核对

    协助者确认这个 ID 存在，看视频里能不能认出是谁、做了什么。缺东西会在查询页留言。

  2. 02

    代投

    站长用自己的 Discord 账号，在 Gakuran Support 的官方举报表单里提交，英文说明由协助者写。

  3. 03

    回执

    提交时间、提交方式和官方的回复都记在你的案件里。没有真正提交，进度就不会显示“已代投”。

本站不要你的密码和验证码。材料只有协助者能看。封不封号由官方决定。
