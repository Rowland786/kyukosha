01要交什么

一共两样：被举报人的 Roblox ID，和一段有效的视频。时间、地点和经过都不用填，想说明的可以写几句。

1Roblox ID用户名或数字 ID 都可以。头顶显示的名字不算。
2视频录下完整经过，能认出是谁。不收 OBS 录屏。

02怎么找对方的 ID

学乱里每个人头顶显示的是角色名，在游戏里可以随时改，所以不能当 ID 用。下面三个地方都能查到 ID，填其中一样就行：

  1. 游戏里的 PLAYERLIST。按左上角 MENU，点 PLAYERLIST，每个角色名旁边就是对应的 Roblox 用户名。上面那张官方示例图左侧高亮的就是这一项。
  2. 对方的 Roblox 主页。主页上大字是显示名称，下面 @ 后面那串才是用户名。
  3. 主页网址。网址里 roblox.com/users/ 后面的那串数字就是数字 ID，整个网址贴过来也可以。

提交时网站会去 Roblox 查这个 ID。查到了会显示对方的用户名和数字 ID 让你确认，查不到会提示你重填。

03什么样的视频有效

从违规开始录到结束，中间不剪、不加速。剪过的视频看不出前后发生了什么。

画面里要能认出是谁。录的时候打开一次 PLAYERLIST，让角色名和用户名出现在同一段视频里。

持续的行为要录够两分钟。比如把人压着不让起身、扛着人不放、把人困在角落，只有几秒钟的片段不够。

不收 OBS 录屏。可以用手机自带录屏、Windows 的 Xbox Game Bar（按 Win + G）或 Medal。

视频可以直接传到本站，单个文件不超过 200MB；也可以贴 B 站、网盘、YouTube、Medal 等链接，要求不登录也能打开，网盘链接请写上提取码。

04哪些行为能报

官方 Trello 的举报说明里列了九种：

Exploiting
外挂、脚本
Bug Abuse
故意利用漏洞
Infinite Holding
无限压制、反复击倒不让起身
Permanent Trapping Players
把人困住出不来
Prolonged Carrying
长时间扛着别人不放
Throwing into the void
把人扔出地图
Extreme Harassment
严重骚扰，持续针对某个人
Explicit Drawings
画色情、下流的东西
Exploiter Affiliation
和开挂的人勾结

在倒地的人身上按着前后键来回晃（W+S）现在不封，明显带性意味的除外。拿不准算不算违规，也可以交上来，由协助者判断。

05交上来以后

你会拿到一个案件编号和一个查询码，凭这两样在“查询进度”里看到每一步。

  1. 核对协助者确认 ID 存在、视频看得清。缺东西会在查询页留言。
  2. 代投站长用自己的 Discord 账号，在 Gakuran Support 的官方举报表单里提交，英文说明由协助者写。
  3. 官方处理批准后 Blox.report 会私信通知；7 天内没人处理会被自动关闭，协助者会重新提交。
  4. 回执提交时间、提交方式和官方回复都会写进你的查询页。没有真正提交，就不会显示“已代投”。

能上 Discord 的也可以自己提交：在 Gakuran Support 服务器的 #reports 点 Report Player，三栏分别填对方的用户名、英文事由和视频链接。

06被封了怎么办

申诉只能本人提交。游戏里被封，去 Support 服务器的 #game-appeals 点 Appeal Ban；Discord 服务器被封，用被封的账号登录 appeal.gg/tzqBhsK7RM。不会写英文的话，Gakuran 主服务器的 #questions 频道里有会说中文的 Helper，可以请他们帮忙。
