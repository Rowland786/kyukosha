01要交什么

只要两样：被举报人的 Roblox ID，和一段有效的视频。时间、地点、经过都不是必填，你想补充就写几句，不写也行。

1Roblox ID用户名或数字 ID 都行。头顶那行字不是 ID。
2视频从头录到尾、看得出是谁。不收 OBS 录屏。

02怎么找对方的 ID

学乱里每个人头顶显示的是角色名，在游戏里随便就能改，所以不能当 ID 用。下面三个地方都能找到真正的 ID，给其中一样就行：

  1. 游戏里的 PLAYERLIST。按左上角 MENU，点 PLAYERLIST，每个角色名后面就是他的 Roblox 用户名。上面那张官方示例图里，左边高亮的就是这一项。
  2. 对方的 Roblox 主页。主页上大字是显示名称，下面 @ 后面那串才是用户名。
  3. 主页网址。网址里 roblox.com/users/ 后面的那串数字就是数字 ID，整个网址贴过来也可以。

提交时网站会当场去 Roblox 查一遍，查到了会显示对方的用户名和数字 ID 让你确认，查不到会直接告诉你。

03什么样的视频有效

从违规开始一直录到结束，中间不剪、不加速。剪过的视频没法证明前后发生了什么，官方也不会认。

画面里看得出是谁。录的时候打开一下 PLAYERLIST，让角色名和用户名出现在同一段视频里，这是最稳的办法。

持续的行为要录够两分钟。压着不让起身、一直扛着走、困在角落出不去，几秒钟的片段说明不了问题。

不收 OBS 录屏。用手机自带的录屏、Windows 的 Xbox Game Bar（按 Win + G），或者 Medal 录都可以。

视频可以直接传到本站，单个 200MB 以内；也可以贴 B 站、网盘、YouTube、Medal 等链接，前提是不用登录就能打开，网盘记得写提取码。

04哪些行为能报

官方 Trello 的举报说明里列了九种：

Exploiting
外挂、脚本
Bug Abuse
故意利用漏洞
Infinite Holding
无限压制、反复击倒不让起身
Permanent Trapping Players
把人困住出不来
Prolonged Carrying
长时间扛着别人不放
Throwing into the void
把人扔出地图
Extreme Harassment
严重骚扰，持续针对某个人
Explicit Drawings
画色情、下流的东西
Exploiter Affiliation
和开挂的人勾结

单纯按着前后键在倒地的人身上晃（W+S）现在不封，明显带性意味的除外。拿不准算不算，照样交上来，协助者会帮你判断。

05交上来以后

你会拿到一个案件编号和一个查询码，凭这两样在“查询进度”里看到每一步。

  1. 核对协助者确认 ID 查得到、视频看得清。缺东西会在查询页留言。
  2. 代投站长用自己的 Discord 账号，在 Gakuran Support 的官方举报表单里提交，英文由我们写。
  3. 官方处理批准后 Blox.report 会发私信通知；7 天没人处理会被自动关闭，我们会重新提交。
  4. 回执提交时间、提交方式、官方回复都写进你的查询页。没真正提交前不会显示“已代投”。

你自己能上 Discord 也可以自己交：进 Gakuran Support 服务器的 #reports，点 Report Player，三栏分别填对方用户名、英文事由、视频链接。

06被封了怎么办

申诉只能本人交。游戏里被封，去 Support 服务器的 #game-appeals 点 Appeal Ban；Discord 服务器被封，用被封的那个账号登录 appeal.gg/tzqBhsK7RM。英文不会写可以问我们。
