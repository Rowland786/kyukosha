谁在办这个站
材料经过谁的手

旧校舍由一位学乱中文玩家开办，用来帮国内玩家把举报材料整理好、按官方流程交上去，同时镜像一份 Kaglorn 整理的服饰图鉴，方便国内打开。本站与 Gakuran 开发组、Support 服务器的员工以及 Roblox 都没有关系。

分工Who does what

一份举报
分四段完成

网站、协助者、官方的 Discord 界面和你自己，各管一段。下面写清每一段由谁来做，哪些事网站做不了，哪些事只能在 Discord 里点按钮完成。

A

网站

收件、存档、记录进度。提交页逐项收集对方用户名、时间地点、经过、聊天原文和证据，并当场去 Roblox 核对用户名是否存在。视频可以直接传上来。提交后生成案件编号和查询码，之后每一次状态变化、每一条留言都记在案件里，你在查询页能看到。

网站不会自动替你举报，也不会和 Discord 自动对接。

B

协助者

站长和帮忙核对的人。在审核台里看录像，核对用户名、PLAYERLIST、时长和类别，缺什么就在你的案件里留言请你补。材料齐了，把中文经过和聊天翻成英文，按 Blox.report 表单三栏的字数写好，原文和译文并排保存。

不是全天在线。新案件一般一到三天内处理，忙的时候会慢一些。

C

Discord 官方界面

真正的提交只能在这里完成：站长用自己的 Discord 账号，在 Gakuran Support 的 #reports 点 Report Player，填三栏、点提交；或者在 Blox.report 网站上传视频后提交。官方的批准通知也是 Blox.report 私信到站长账号，再由协助者抄进你的案件。

我们不用脚本、机器人或任何自动化去操作 Discord 账号，每一次提交都是在正常界面里手动完成的。

D

你自己

录像、交材料、按留言补材料。申诉（游戏封禁和 Discord 封禁）必须由被封的人自己提交，我们只帮你把英文写好、把步骤列清楚。

你不需要给任何人密码、Cookie 或验证码。

进度里每个状态的意思

已收件
材料已经存进系统，还没有人看。
核对中
协助者正在看你的材料。
待补充
缺东西，查询页会写明要补什么。补交以后自动回到“核对中”。
待提交
材料核对完、英文写好了，等站长在 Discord 里提交。申诉案件到这一步，是请你本人提交。
已代投
站长已经在官方表单里点了提交。只有真正提交以后才会出现，并写明提交时间和方式。
官方已回复
收到了 Blox.report 的私信或员工的答复，按原意写进结果。没有收到回复，就一直停在“已代投”。
已结束
不能代投（比如不属于可举报行为、证据无法补救）或你撤回了，原因会写明。
隐私与访问控制Privacy

材料只给
需要看的人看

你提交的举报材料、上传的视频、留下的联系方式，都存在收件后台（Netlify 的私有存储），不在本站的公开页面上，也不会写进 GitHub 仓库或 Issues。能打开这些材料的只有两种人：持有案件编号和查询码的你，以及登录审核台的协助者。

你在查询页能看到自己交的内容、进度和协助者给你的留言，协助者的内部备注不会出现在那里；协助者在审核台能看到全部材料，包括你的联系方式。查询码只在提交成功那一刻显示一次，服务器只保存它的校验值，忘了就找不回来。

交到官方那边的，只有表单要求的三栏：对方的 Roblox 用户名、英文事由和证据链接，以及必要时上传给 Blox.report 的视频。你的称呼和联系方式不会交给官方，除非官方要求联系当事人，那时会先问你。

案件结束后，材料和视频保留 180 天，之后由后台定时删除。想提前删除，在查询页留言说明即可。

我们不会向你要 Roblox 或 Discord 的密码、Cookie、两步验证码，也不需要你登录任何东西。以旧校舍名义索要这些的，都不是我们。站长的 Discord 登录凭据同样不会出现在网站或源码里。
