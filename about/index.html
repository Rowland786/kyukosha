关于本站

谁在办
这个网站

旧校舍由超工口级魔法少女制作，是学乱中文玩家自己办的网站。它帮国内玩家把举报交给官方，也镜像了一份 Kaglorn 整理的服饰图鉴。本站和 Gakuran 开发组、官方员工、Roblox 都没有关系。

01
分工

每一步由谁来做

A

你

提交对方的 Roblox ID 和一段视频。需要补材料时，按查询页的留言补交。

不用给任何人密码、Cookie 或验证码。

B

网站

收件，去 Roblox 核对 ID，保存视频，记录每一步进度。

网站不会自动替你举报。

C

协助者

看视频，确认对方身份，写英文说明。缺材料时留言请你补。

不是全天在线，新案件一般一到三天处理。

D

官方表单

站长用自己的 Discord 账号，在 Gakuran Support 的 #reports 里点 Report Player 正常提交。官方的回复也发到这个账号，再由协助者抄进你的案件。

每次都在官方界面手动提交，不用脚本或机器人。

已收件
材料到了，还没人看。
核对中
协助者正在看。
待补充
缺东西，查询页写着要补什么。补完回到核对中。
待代投
核对完了，等站长去官方表单提交。
已代投
真正在官方表单里点了提交才会出现，写明时间和方式。
官方已回复
收到官方回复才会出现。没收到就一直停在“已代投”。
已结束
没法代投或者你撤回了，会写明原因。
隐私

材料怎么保存

你交的视频、ID 和联系方式存在收件后台的私有存储里，不会出现在公开页面上，也不会进 GitHub 仓库或 Issues。只有持有查询码的你和登录审核台的协助者能打开。

查询码只在提交成功时显示一次，服务器只存它的校验值，忘了就找不回来。

交给官方的只有对方的用户名、英文事由和视频。你的联系方式不会给官方。

案件结束 180 天后，材料和视频自动删除。想提前删，在查询页留言。

本站不会向你要 Roblox 或 Discord 的密码、Cookie 和验证码。用旧校舍名义索要这些的，都不是本站。

02
图鉴镜像

镜像了什么，没镜像什么

服饰图鉴的数据、图片和中文整理来自 Kaglorn 的学乱服饰图鉴，素材出自官方 Trello。本站按上游仓库的文件树逐个下载，每个文件都用 git 校验值和上游比对。下面的数字由镜像清单实时算出。原仓库没有声明许可证，镜像只为方便国内查阅，不改动原数据和署名；作者如有异议，本站会立即处理。
